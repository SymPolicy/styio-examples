# Authorship policy

Cursor Cloud Agent PRs are **drafts only**. Do not merge them.

1. Re-author the same tree as GitHub user `Unka-Malloc`.
2. Open a human-signed PR.
3. Close the Cursor PR without merging.

CI workflow `reject-cursor-authors` fails if any commit on the PR is still Cursor-authored, so a draft cannot be merged by mistake.
